# Documentation source migration

The former Documentation aggregate is retired. Install reusable Components such as Code block, Callout, Example, Mermaid, F# API reference, Browser, and Phone independently.

Applications, specifications, and API sites are ordinary consumer-authored HTML. The catalog provides exactly three cohesive financial templates, with complete model, layout, page, routing, hosting, project, and setup source.

See [Components and source migration](../README.md). Repository-only legacy rendering support lives in `Templates/`; it is not distributed by the CLI and is not part of copied templates.
